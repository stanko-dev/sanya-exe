# sanya.exe

Шкільна 2D top-down аркада-подарунок на JavaScript, Phaser 3 та Vite. Три рівні, 10 / 12 / 15 мультяшних суперників, безлімітні постріли конфеті, фото й побажання після кожного рівня. Без крові, backend, бази даних і платних сервісів. Уся початкова графіка намальована програмно, сторонні медіа не потрібні.

## Запуск

Потрібен Node.js **22.12+** (або 20.19+) та npm.

```sh
npm install
npm run dev
```

Відкрити адресу з термінала, зазвичай **http://127.0.0.1:5173/sanya-exe/**. Для роботи потрібні клавіатура й миша; керування дотиком не реалізовано.

```sh
npm test          # перевірка прохідності карт і конфігурації
npm run build    # production → dist/
npm run preview  # локальна перевірка production-збірки
```

## Керування і правила

- **WASD** — рух, миша — приціл, утримання **ЛКМ** — конфеті.
- **Esc** або кнопка **Ⅱ** — пауза з гучністю та виходом у меню.
- Рухайся між партами й тримай дистанцію. Кожен суперник має HP і завдає контактної шкоди з перезарядкою. Після влучання гравець отримує коротку невразливість.
- Відправ усіх суперників на перерву, тоді пройди до зелених дверей **угорі по центру**. Відкриється листівка з фото й кнопкою наступного рівня.
- При поразці **Restart** або **R** перезапускає поточний рівень. Після третьої листівки — фінальне привітання.
- Гучність запам’ятовується локально; прогрес проходження не зберігається. Без наданих MP3 гра беззвучна. Браузер може дозволити музику лише після першого кліку.

## Фото та звуки

Папки вже створено. Додай **справжні** PNG / MP3 із такими назвами (регістр важливий для GitHub Pages):

```text
public/media/
  menu/
    background.png            # фон меню, бажано 1280×800
    soundtrack.mp3            # музика меню / фіналу
  lvl1/
    face_lvl1_1.png           # Відмінник
    face_lvl1_2.png           # Фізрук
    input_sound_lvl1_1.mp3    # Відмінник отримав шкоду
    output_sound_lvl1_1.mp3   # Відмінник успішно атакував
    input_sound_lvl1_2.mp3
    output_sound_lvl1_2.mp3
    reward_photo.png
    soundtrack.mp3
  lvl2/                       # ті самі назви з lvl2; типи 1, 2, 3
  lvl3/                       # ті самі назви з lvl3; типи 1, 2, 3
  common/                     # місце для власних спільних ресурсів
```

Для `face_lvlN_M.png` **N** — номер рівня, **M** — `id` типу ворога. Бажано квадратний PNG з прозорим фоном і обличчям, спрямованим праворуч; у грі зображення масштабується до 46×46. Фото листівки можна будь-якого розміру: воно вписується з кадруванням. Особисті фото додавай за згодою зображених людей.

Відсутні ресурси взагалі не запитуються: Vite збирає список реальних файлів. Замість облич — процедурні персонажі, замість фото — намальована листівка; відсутні звуки пропускаються. Пошкоджений ресурс пропускається з попередженням у консолі. Після додавання медіа перезапусти dev-сервер або виконай нову production-збірку.

## Баланс і персоналізація

У **`src/config/levels.js`** змінюй:

- `playerConfig`: HP, швидкість, шкоду, інтервал пострілів і невразливість.
- `enemies` кожного рівня: окремі `hp`, `speed`, `damage`, `count`, `attackCooldown`, `color`, `media` для кожного типу.
- `title`, `room`, `subtitle`, `rewardTitle`, `wish`: назви та побажання.
- `rewardPhoto`, `soundtrack`: шляхи відносно `public/media/`.
- `obstacles`: парти й перегородки `{ x, y, w, h, kind: 'desk' | 'wall' }` у координатах 1280×800. Залишай проходи шириною щонайменше 80 px, вільну стартову позицію `(640, 692)` та доступ до виходу `(640, 122)`.

Увесь текст фінального привітання — у `src/scenes/EndScene.js`. Спільні графічні заглушки — у `src/lib/art.js`. При зміні геометрії запускай `npm test`, щоб виявити відрізані проходи. Для медіа в `common/` указуй шлях у конфігурації, наприклад `common/reward_photo.png`.

## Структура

```text
src/config/levels.js     баланс, типи суперників, карти й побажання
src/scenes/BootScene.js  завантаження наявних медіа, заглушки
src/scenes/MenuScene.js  меню, керування, гучність
src/scenes/GameScene.js  фізика, бій, HUD, пауза, вихід
src/scenes/RewardScene.js фото, побажання, статистика
src/scenes/EndScene.js   поразка / фінальне привітання
src/lib/                графіка, пошук шляху, медіа, DOM-інтерфейс
```

## GitHub Pages

`vite.config.js` задає `base: '/sanya-exe/'`. Налаштування відповідає [документації Vite для GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages).

1. Створи репозиторій **sanya-exe**, завантаж код у гілку **main**. Після першого `npm install` додай створений `package-lock.json` до репозиторію для фіксації версій залежностей.
2. У репозиторії відкрий **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Push у `main` або ручний запуск **Actions → Deploy sanya.exe to GitHub Pages → Run workflow** запускає тести, збірку й деплой.
4. Гра буде доступна за `https://<username>.github.io/sanya-exe/`.

Для іншої назви репозиторію зміни `base`. Усі URL медіа враховують цей префікс. Не завантажуй `node_modules`; `dist` створює workflow. GitHub Pages публікує всі додані фото та звуки разом із грою.
